# Still Runs!

One-button HTML5 arcade driving game, maintained independently from aynen.fun.

## Play
https://still-runs-pi.vercel.app/

## CrazyGames submission

The game uses a standalone `index.html`, with no additional runtime assets.

**Get the upload ZIP:** GitHub → Actions → Package CrazyGames → most recent successful run → Artifacts → `still-runs-crazygames-upload`. Download the artifact and unzip it once; upload the enclosed `still-runs-crazygames.zip` to CrazyGames.

Or run `sh package.sh` locally to generate `dist/still-runs-crazygames.zip`.

## Controls
Hold mouse/touch accelerator, Space or Up Arrow to accelerate. Release to slow down and level out. Drive through 16 terrains. Reach the cyan finish line after the black hole.

## Before submission
- Test desktop Chrome and mobile Safari/Chrome.
- Test all four vehicles, touch controls, audio/mute, replays, restart, black-hole ending.
- Record actual gameplay previews if requested by CrazyGames.
- Check licensing and artwork usage.
- Basic Launch build; CrazyGames SDK is not integrated.
